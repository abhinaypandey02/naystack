    OptionalalwaysResolve

    alwaysResolve?: boolean

    Skip FieldLibrary's short-circuit, which returns a pre-hydrated root[key] without ever calling this resolver.

    Set this on any field that gates on ctx — an auth check inside the resolver is silently bypassed the moment a parent query selects the field's value into its own columns. The resolver stays responsible for reusing root[key] when present, so hydration still avoids the N+1.
